### Как установить

1. Установите [Fabric Loader](https://fabricmc.net/) версии **0.19.2+**
2. Установите [Fabric API](https://modrinth.com/mod/fabric-api) версии **0.146.1+26.1.2**
3. Скачайте **wardenupgrade-1.0.0.jar** (ссылка выше)
4. Поместите `.jar` в папку `mods/` вашего Minecraft
5. Запустите игру!

## Описание

Мод превращает обычного Вардена в мощного 3-стадийного босса с кастомным HP-баром, эффектами частиц и новым снаряжением.

Игрок пишет в чат фразу **`Wardenio upgrade doe level.`** — и ближайший Варден начинает эпическую трансформацию.

---

## Возможности

### Трансформация Вардена
- 5-секундная анимация: левитация, частицы Soul Fire, звуки грома
- HP увеличивается до **500**
- Урон x3, скорость x1.5, полная устойчивость к отбрасыванию
- Зловещая голубо-синяя аура из частиц

### 3 стадии (по % HP)

| Стадия | HP | Цвет Boss Bar | Эффекты |
|--------|----|---------------|---------|
| 1 | 100% — 66% | Голубой | Базовое усиление |
| 2 | 66% — 33% | Фиолетовый | Урон x1.5, скорость x1.3 |
| 3 | < 33% | Красный | Урон x1.5, скорость x1.5 |

При переходе между стадиями:
- Тряска экрана у всех игроков
- Звук `entity.wither.spawn`
- Сообщение в чат: *"Варден впадает в ярость! Стадия X"*

### Новые предметы

| Предмет | Описание | Крафт |
|---------|----------|-------|
| **Стрела Бедствия** | Стан 0.5 сек + урон от увядания 3 сек | Осколок эха + палка + перо |
| **Меч Героя** | 3x характеристики незеритового меча | Алмазные блоки + незеритовые блоки |
| **Шлем Героя** | 3x защита незеритового шлема | Алмазные блоки + незеритовые блоки |
| **Нагрудник Героя** | 3x защита незеритового нагрудника | Алмазные блоки + незеритовые блоки |
| **Поножи Героя** | 3x защита незеритовых поножей | Алмазные блоки + незеритовые блоки |
| **Ботинки Героя** | 3x защита незеритовых ботинок | Алмазные блоки + незеритовые блоки |

## Как использовать

1. Убедитесь, что **Эндер Дракон жив** (не убит)
2. Найдите или заспавните **Вардена**
3. Напишите в чат: **`Wardenio upgrade doe level.`**
4. Наслаждайтесь эпической трансформацией!

---

## Технические детали

- **Платформа:** Fabric + Fabric API
- **Minecraft:** 26.1.2
- **Java:** 25+
- **Без Mixins** — только Fabric API хуки (`ServerMessageEvents`, `ServerTickEvents`)
- HP-бар реализован через `ServerBossEvent` (Boss Bar)
